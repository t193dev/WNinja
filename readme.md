
# WNinja

An original ESP32 wireless security monitoring toolkit.

## Hardware
- ESP32 Cheap Yellow Display (CYD)
- 2.8-inch touchscreen
- MicroSD storage

## Development
- C++
- Arduino Framework
- PlatformIO

## Features
- Wi-Fi monitoring
- Bluetooth scanning
- Deauthentication detection
- Wireless security alerts
- Touchscreen dashboard
- Device logging

0.1.0 - Initial development
